SANKOFA CHESS - install on your phone

1. Go to github.com -> New repository -> name it "sankofa-chess" (Public).
2. "uploading an existing file" -> drag in ALL files from this folder
   (index.html, manifest.webmanifest, sw.js, the 4 PNG icons). Commit.
3. Settings -> Pages -> Source: "Deploy from a branch", Branch: main, folder / (root). Save.
4. After ~1 minute your app is at:  https://<your-username>.github.io/sankofa-chess/
5. On your phone open that link:
   - iPhone (Safari): Share button -> "Add to Home Screen"
   - Android (Chrome): menu (three dots) -> "Install app" / "Add to Home screen"

It then opens full-screen with the Sankofa icon, and works offline after the first visit.
Progress is saved on that phone. The live AI coach only works inside the claude.ai
version; the installed app uses the built-in offline coach.
